# Sag Calculator

A free, phone-friendly motorcycle suspension sag calculator. Enter travel, pick a riding style, and it tells you which way to adjust preload.

**Live:** https://jpott09.github.io/sag-calculator/

Made by [BackroadADV](https://www.youtube.com/@BR-ADV). It's plain HTML, CSS and JavaScript, with no build step, no backend and no tracking. Your data is saved only in your own browser.
